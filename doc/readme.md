## Documentation

This folder contains both German and English versions of the documentation related to the internship presentation (each in there own folder). The same applies to the task descriptions for the two main challenges that participants are expected to complete during the internship.

The internship presentation is available in both languages:

* **English:** https://prezi.com/view/5wvkttqPa2XyF3pv1Qpp
* **Deutsch:** https://prezi.com/view/92QVkWSRnhqyHrl9Wt4x

Additional documentation and supporting material can be found in the corresponding language-specific files within this directory.

For more detail on how to use and execute the different task, please refer to the readme.md files in the task folders.
